# 写作规范

写任何一章之前先读这一份。它合并了原来的概念地图、理论对齐、写作手册。

配套：`大纲.md`（写什么）、`评审记录.md`（到哪儿了）。

## 零、核心术语锚点（2026-09-11 新增）

以下术语在全书首次出现时，必须给出明确锚点，让读者知道"在这个语境下，它指的是X"。不同章节含义略有不同时，需说明"这里说的是X的另一面"。

| 术语 | 锚点定义 | 首次出现 | 不同用法说明 |
|------|----------|----------|--------------|
| **熵** | 随机性。系统可能处于的状态越多，熵越大 | 第1章 | 第2章：被控制挤走的混乱；第8章：生命主动摄入的随机性 |
| **编码** | 系统控制方式的表达。一家公司的规章制度、一门语言的语法、一个物种的基因序列，都是编码 | 第7章（或更早） | 论文是一种编码、营收是编码、共情编码——什么都可以是编码，因为它指的是"任何一套规则/范式/做事方式" |
| **压缩映射** | 把大的可能性空间压进小的范围。每次控制都在做这件事 | 第2章 | 不需要数学记号，用日常语言说清即可 |
| **维度** | 事情可以变化的方向。"分子自由度"是一个维度，"情绪"是一个维度 | 第2章 | 不同维度之间可比性在于：都是熵可以流动的通道 |
| **反脆弱性** | 系统能存活的整体能力。不是某一条控制曲线的峰值高度，而是维度分布图是否"紧的地方刚好紧、松的地方刚好松" | 第4章 | 它不是"好的系统"的另一个名字，而是"好的系统"之所以好的那个属性 |
| **散热带宽** | 系统释放熵的能力上限。不是所有维度都能当外机，能当的也有上限 | 第3章 | 两层天花板是它的不同方面 |
| **策略空间** | 系统能走的备选路径。意外来时，有没有别的路可走 | 第4章 | 不要用"策略空间"，说"还有没有别的路" |
| **编码进化循环** | 新约束→新组合→新问题→更新的约束。这是进化的引擎 | 第7章 | 也叫"编码进化循环"，是正反馈 |

## 一、概念归属（作者亲定，不得擅自改动）

### 1. 主线概念：五个，加上一个"怎么提升"

| 概念 | 说明 |
|---|---|
| **系统** | **不言自明**（这本书就叫系统理论）。不要下重定义，用具体物带出来 |
| **熵** | **第一个核心概念。** 从"可能性有多少"入手。（理论里的推演路径是从非线性动力系统到随机性——**这条路径不必进正文**） |
| **控制** | 不必是术语，但要表达"**在几个可能里挑一个**"。它存在的唯一作用是引出**控制导致熵转移**（搬运熵） |
| **反脆弱性** | **全书的中心。** 它描述系统健康度、不容易解释，**所以值得花更多篇幅讲清楚** |
| **编码** | **理论的核心工具**——用它解释问题会清晰很多。保留 |

**"怎么提升反脆弱性"那一层，其实就是换个方式讲进化论。**

### 2. 反脆弱性怎么讲（作者给的路径）

**刚性和柔性这两个词，存在的唯一目的就是跟反脆弱性加以区别**——因为人们往往有误区：

1. 先给两个中性描述：**刚性＝控制更多，柔性＝控制更少**，都不带褒贬。
2. **误区一**：以为控制越多越稳（把刚性当反脆弱）→ 玻璃碗。
3. **误区二**：以为撤掉控制就有弹性（把柔性当反脆弱）→ 一滩水、彻底放权的团队。
4. **两条腿**：控制力 ＋ 还有没有别的路。
5. **反脆弱性定义在系统整体上**，不是单条控制上；控制一条条加总，不等于它在涨。
6. **结论**：反脆弱性不是对控制总量的加减法，**是分布**——所以要问"控制落在了哪些维度上"。

**与塔勒布的关系**：这个词他先立起来，他给的是一套**方案**；本书问的是另一个问题——从系统整体往下推，**反脆弱性必须具备哪些性质、又一定不能具备哪些性质**。不要写成"他错了"，也不要写成"我用的不是他的意思"。

### 3. 理论有、但可以用更好懂的说话方式

作者原话："散热带宽、策略空间其实都不是我原本需要的术语，都可以找更加容易理解的方式表达。"

| 理论用语 | 科普书改用 |
|---|---|
| **散热带宽** | 说"往外排的那个口子"、"这个口子有多大"、"不是所有东西都能挂到外面去"。**不必立这个名字** |
| **策略空间** | 说"还有没有别的路可走"。**不必立这个名字** |

### 4. 只为定义清晰、科普书不必纠结

**演化 / 进化 的区分。** 作者原话："区分演化和进化，也只是为了追求一些定义上的清晰，回到科普书可以不需要这么严格的纠结这些定义，整体读者看得懂而且没有歧义就好。"→ 保留一句不含歧义的区分即可，**不要做成要读者记的术语**。

### 5. 其他学科引入的概念（不是本理论重点）

**均衡态、纳什均衡**等。它们可以出现，但**不要作为本理论的核心词来立**。它们的作用只有一个：向**对其他学科有了解的人**解释系统理论和他们熟悉的那个学科**分歧在哪**——要写明"这是那个学科的说法，我们这里要说的是另一件事"。

### 6. 应用层面推演出的现象

**"自指闭环"**（系统只从自己那套编码里找解释、找方案）。作者说它"算是一个系统理论在应用层面推演出来的现象，你可以看看有没有更合适的词语描述。这个词可能也是其他领域拿过来用的。"→ 现象保留，**名字待定**。

### 7. 不是作者的概念，是从案例里来的

**"三道门"**（外面有人敲／圈里公开承认不懂／圈里发现怎么修都修不好）。作者明确："**不是理论概念，降为案例描述。**"→ 可以在讲那件案例时描述这三种条件，但不要把它立成一条定律、也不要起新名字。

### 8. 🚫 禁用：我（助手）在写作过程中自己造的词

作者原话："你那里说得什么杠杆层、断拍之类的概念，**不是我的概念**，应该是你反复写作的过程中自己形成的术语。"

| 禁用 | 改用什么 |
|---|---|
| **断拍** | 说"进化的引擎还在不在转"，或者直接说清是哪一头没了 |
| **杠杆层** | 说"哪一层改得动"。**理论的三句话诊断里没有这一步** |
| 压缩映射 | 改用"压缩""把可能性压小"（理论文档与白皮书保留正式术语） |
| 元系统 | 改用"规则本身也在变" |
| 路由 | 改用"谁处理什么、处理完交给谁" |
| 规模病 / 扩张依赖 | 改用"人一多，通道就稀释""把增长焊成不能碰的硬指标" |

**"松紧表"这个名字可以留**（作者说过表名不规定），但要知道理论的原名是**控制分布图 / 维度分布图**，那是理论里的正式说法。全书的表名统一为"松紧表"，不得出现"维度表""控制分布图""维度分布图"。

## 二、理论口径（不得写反）

### 编码进化循环＝两半拍（作者亲定）

> **碰撞和组合合起来带来熵增；筛选带来新编码，也就是熵减；熵减的结果就是新编码，又开始新一轮碰撞和组合。**

- **熵增那一半：碰撞 ＋ 组合**——新的、旧的编码撞上，各种搭配冒出来，可能性暴增。
- **熵减那一半：筛选**——现实从一堆搭配里挑出能活的，收敛成**新编码**。
- 新编码成为下一轮的材料。这就是循环自己踩油门的原因。

**最常见的写错**：写"碰撞产生新编码＝熵减"（方向反了）；把筛选说成"循环外面的一道理性审查"。

### 不是本理论提出的（写文章时最容易混进来）

| 说法 | 真实来源 | 正确处理 |
|---|---|---|
| 生命靠吃"**低熵物质**"活着 | 薛定谔《生命是什么》 | 引用时明确归给他，并指出它"说到一半" |
| "以熵为食"＝吃进低熵 | 不是本理论 | 本理论：**负熵说的是排出的那一头；以熵为食说的是摄入的那一头，进来的不是"有序"，而是新的、还没被消化过的随机性。** 原话：**"一片叶子的价值不在它多有序，在于它带来了这个身体还没处理过的东西。"** |
| "反脆弱＝越挫越强" | 塔勒布 | 那是一种方案，不是定义 |
| "熵"当作可计算的物理量 | 热力学 | 本书只用它的结构含义：可能性多不多、余量还有没有。要算焦耳、要读温度的时候，那是另一套语言 |

### 诊断工具：理论自己的只有三句话

> ① **控制落在了哪些维度上？**（熵只能搬运，所以先问控制在哪）
> ② **哪些维度已经快要喘不过气？**（转移必有承受方，所以问谁在扛）
> ③ **熵正在往哪里流？**（承受方到极限会继续转移，所以问它会把压力扔给谁）
>
> 然后问到底：**这套控制体系，是在给进化留空间，还是在把进化的门一扇一扇关上？**

理论自己的评价："这三句话没有一丁点神秘，是同一条逻辑的三次连续转弯。"

**不要再加层**（不要"五步""体检表""三列证据""杠杆层四步"——那些是我加的，九轮读者里有六轮说它像操作手册）。

## 三、写作红线

- **中文双引号** “”，不用「」。**ASCII 连字符** `-`，不用 U+2011。
- **去 AI 味**：删"值得注意的是""此外""然而"这类填充语；禁否定式排比（"不仅……而且……"）；破折号与粗体克制。
- **让矛盾自己说话**：摆出事实的冲突面，删掉所有替读者做情绪判断的形容词。
- **概念为叙事服务**：把术语全删掉，文章还要站得住。
- **口语化但不轻浮**：像兰小欢《置身事内》。
- **不要"指路句"**："这就是开头那个问题的来历""这一章剩下的部分都围着它转"——读者不需要被告知结构，需要被带进去。
- **不要"作者的过程"**：不要解释"为什么这么推""为什么不用别的词""为什么这不是换一个指标"。这些对审稿人有用，对读者是负担。**优秀科普和合格科普的差别，往往就是敢不敢把作者自己想通的过程删掉。**
- **不要替读者下判决**：如果前面说"每个人做的都是当下最合理的选择"，就不要在结尾说"控制落在了不该落的地方"——"不该"没有依据。让读者自己得出结论。
- **不编造**数据、人名、机构、日期。构造的案例要交代一句（"这是合成的，但每一环都来自现实里反复出现的形状"），但同一句式全书只用一次。

## 四、每章结构

1. **开头一个问题**（读者自己会问的具体问题）。
2. 中段：从场景里长出概念，**不要先定义后举例**。
3. **章末回答那个问题**，然后收束。禁止"总结一下""综上所述"。

---

## 五、反重复的三条硬规则

1. **同一个结论，全书只完整出现一次。** 别处一律短回指。
2. **术语复现可以，段落重讲不行。** 一个概念推完之后，不能在另一章换个说法再推一遍。
3. **一个案例只承担一件事。** 如果一个案例没有承担新的论证任务，只是把同一句话再说一遍，就删。

**判断标准**：一段话如果删掉之后，读者对世界的理解不变、只是少知道作者是怎么想的，那它就是可以删的。

## 六、跨章引用规则（2026-09-11 新增）

后面章节引用前面章节的概念时，必须遵守：

1. **首次引用必须有锚点**：用一句话说清"这是第X章讲过的Y"，不要假设读者记得
2. **不要只带过**：如果一个概念对本章论证重要，需要花 1-2 句话简要回顾其核心含义
3. **不要用"我们说过""前面讲过"这种空指**：要具体说"我们说过 X"，让没读过前文的读者也能跟上

**反面教材**：
- ❌ "上一章我们讲过散热带宽的回旋镖"（空指，读者不知道散热带宽是什么）
- ✅ "第三章讲过，系统释放熵的能力有上限，超过就会出事。这个上限现在叫散热带宽"

## 七、一物一名

同一层的东西只能有一个名字；从属的明确挂到主词下面。

| 主词 | 处理 |
|---|---|
| **编码** | 总名（"图纸""蓝图"这类别名已删）。第四章的**松紧表**是编码的一种画法 |
| **熵 / 搬运熵** | 保留，不再给别名 |
| **排热口** | 一体两名：**排热口**（通道）／它的**上限**。不得出现"呼吸口""散热口" |
| **缓冲层** | 与排热口并列时要给对照：**排热口是往外排的，缓冲层是往里垫的** |
| **反脆弱性** | 总名，两条腿：控制力 ＋ 还有没有别的路 |
| **进化** | 两半拍（碰撞＋组合＝熵增；筛选＝熵减） |

**注意**：一个词的**第一次出现必须挂在一件具体的事上**，不许挂在另一个新词上。（这是九轮读者里反复出现的问题——"编码是从碰撞里长出来的，碰撞又要用新编码当材料"，读者像在咬自己的尾巴。）
