# 写作规范

## 零、这份规范怎么用（2026-09-17 补）

**这里的每一条都是默认值，不是硬约束。** 逐章检查时按它执行；碰到具体问题时，如果放宽能让那一处更清楚、更顺、更像人写的，就放宽——太严的规定会把手写死，反而伤文章的流畅。

判断的唯一标准：**改完之后，读的人是不是更顺了。** 是，就改；不是，哪怕它符合规范也不改。

下面凡写“不得”“禁止”的，都按这个口径理解：先看看放宽会不会更好。

## 一、术语与命名

### 给锚点的（首次出现必须挂在具体的事上，不许挂在另一个新词上）

| 术语 | 锚点 | 首现 |
|------|------|------|
| **熵** | 随机性。系统可能处于的状态越多，熵越大。**只用这个结构含义，不算焦耳；要读温度时那是另一套语言** | 第2章 |
| **压缩**（理论里叫压缩映射） | 把大的可能性空间压进小的范围，每次控制都在做这件事。**正文只说“压缩”“把可能性压小”，不出现“压缩映射”。数学记号一般换成文字（它常常比文字更难懂），但不当成禁令** | 第2章 |
| **维度** | 事情可以变化的一个方向，也是一条混乱能流过去的通道 | 第2章 |
| **编码** | 系统控制方式的表达。公司规章、语言语法、基因序列都是编码 | 第7章前 |
| **反脆弱性** | 系统能存活的整体能力。不是某条控制曲线的峰值，是分布对不对 | 第4章 |
| **编码进化循环** | 新约束→新组合→新问题→更新的约束 | 第7章 |

### "维度"怎么用（2026-09-11 补）

读者反复说它抽象。不换名字（松紧表就是"一个维度一行"，换掉那张表就无处安放），换用法：

- **第一次出现给两个说法**：抽象的（事情上可以变化的一个方向）＋可操作的（画成表，它占一行；上一次出事混乱从哪儿漏出来，那儿就是一个维度）
- **日常句子里优先大白话**："哪几个方向""哪儿紧哪儿松""哪一头"；"维度"留给需要精确指代的地方——控制落在哪几维、松紧表的一行
- **第一章不出现这个词**（那里只说"走法""方向"），第二章第一次给它命名

### 不立名字的（只用大白话）

散热带宽 → “往外排的那个口子”“这个口子有多大”；策略空间 → “还有没有别的路走”；系统 → 不言自明，用具体物带出来，不下重定义；均衡态／纳什均衡 → 不是本理论的词，只在向其他学科的人说明分歧时出现；自指闭环 → 现象保留，名字待定；三道门 → 不是概念，降为案例描述。

### 禁用（写作过程中助手自己造的词）

| 禁用 | 改成 |
|---|---|
| 断拍 | “进化的引擎还在不在转”，或直接说清是哪一头没了 |
| 杠杆层 | “哪一层改得动” |
| 压缩映射 | “压缩”“把可能性压小” |
| 元系统 | “规则本身也在变” |
| 路由 | “谁处理什么、处理完交给谁” |
| 规模病／扩张依赖 | “人一多，通道就稀释”“把增长焊成不能碰的硬指标” |

表名只用**松紧表**（不得写“维度表”“控制分布图”“维度分布图”）。

## 二、理论口径（不得写反）

### 主线链条（作者亲述，不得写错）

1. 世界底色是随机的：一件事本来有很多种走法。
2. **我们对系统做的任何事都叫控制。** 控制唯一的表现形式：**让某个维度上的可能性变小**。（数学上叫压缩映射，正文不出现这个词。）
3. 一个维度上的可能性变小，其他维度上的可能性必然变大。为了表达"可能性"这个量，引入**熵**——数学的熵；物理熵和信息论熵都是它在具体领域的展现。
4. **控制和"系统会不会崩"没有直接关系。** 所以引入新标准：**反脆弱性**。它不是绝对量：高不等于不会崩（世界底色是随机），但与"不崩的概率"正相关。
5. 系统理论要研究的课题因此可以写出来：**怎样的控制，能持续提升系统的反脆弱性。**
6. 刚性和柔性都不是反脆弱性，两个极端反而更低。**没有一个能直观说明"反脆弱性高"的例子**——所以从第五章起，大量章节处理的是"**反脆弱性什么时候不高**"。这局面要到讲进化那一章才缓解，但仍不解决：进化可以无止境，反脆弱性"高"没有上限也没有标准，**这本书只能比较出哪些情况不够好**。

**由此推出两条写作约束**：

- **不要把"控制"写成换过意思的词**（挑走一条路／压缩可能性／系统不崩／每维约束量，是同一个概念的不同层级）；也**不要为"熵"借用物理语气而道歉或设防**——它是数学的量，跨领域使用是它的本分。这两点各被读者当成缺陷报过一轮，其实是误读，写正文时不必迁就。
- **不要承诺"这里没事"的判定。** 这本书能给的是比较，不是阈值。读者问"什么时候算够好"，答案是：把更差的那种指出来，删掉它。


**编码进化循环＝两半拍**：碰撞＋组合＝熵增（可能性暴增）；筛选＝熵减（收敛成新编码）；新编码成为下一轮的材料。最常见的写错是“碰撞产生新编码＝熵减”（方向反了），和把筛选说成“循环外面的一道理性审查”。

**不是本理论说的**：生命靠吃“低熵物质”（薛定谔，引用时要指出它只说了一半）；“以熵为食”＝吃进低熵（本理论说的是摄入**新的、还没被消化过的随机性**，排出的那一头才叫负熵）；“反脆弱＝越挫越强”（那是塔勒布给的方案，不是定义）。

**诊断工具只有三句话**：控制落在哪些维度上？哪些维度快喘不过气？熵正往哪里流？然后问到底：这套控制是在给进化留空间，还是在把门一扇扇关上。**不要再加层**（五步、体检表、杠杆层四步都不要）。

## 三、写作红线

- 中文双引号 “”，ASCII 连字符 `-`。
- 去 AI 味：删“值得注意”“此外”“然而”；禁否定式排比；破折号与粗体克制。
- **让矛盾自己说话**：摆出事实的冲突面，删掉替读者做情绪判断的形容词。
- **概念为叙事服务**：把术语全删掉，文章还要站得住。
- **不要指路句**：“这就是开头那个问题的来历”“这一章剩下的部分都围着它转”。
- **不要作者的过程**：不解释“为什么这么推”“为什么不用别的词”。优秀科普和合格科普的差别，常常就是敢不敢把作者自己想通的过程删掉。自我检讨、局限声明、方法的元讨论，一律去掉起手句（“反过来问一句：……”“还有一处得认：……”），改成正面陈述，内容照留。
- **不要自我免责（2026-09-17 补）**：不写“这本书举不出几个”“还没有实践案例”“一个对照组都没有”“别把它当药方”“这不是配方”“这份样本不算硬气”这类话。

  这套理论还不为大众熟悉、能拿出来的应用案例不多，是它现在的处境，**坦然接受就行**——读者有这个疑惑很正常，不必在正文里提前消毒。科普书不是法律条款，不需要给每一句话配上免责声明。

  区分两种东西：**自我免责**（为预防质疑而写的声明）删掉；**证据等级标注**（“这个故事出自后人笔记，未必真发生过”“这是指控，不是判决”）和**可证伪的预测**（“如果三年内先听见某类学校成批停招，那我输了”）留着——前者是诚实，后者是科学态度。
- **不要替读者下判决**：说了“每个人做的都是当下最合理的选择”，就别在结尾说“控制落在了不该落的地方”。
- **分清证据等级**：分子扩散和“管了价格就有黑市”不是一个证据等级。前一半是物理，后一半要说成“反复被看见的经验”。两层混在一句里，懂一点热力学的读者会当场撤信任。
- **不编造**数据、人名、机构、日期。

### 句子节奏（2026-09-17 补）

治一个毛病：**句子节奏单一**。连着几段都是“连接词起手 → 陈述 → 转折”，读起来像同一个句式在复读。

每段换一个起手式：因果衔接 / 短句气口 / 主语加类比 / 举例 / 主语加断言 / 反诘。

三个坑：

- **连着两个设问**：“为什么 A？因为……”接“为什么 B？因为……”——内容换了，节奏没换。
- **同一个句式复读**：一个句式用两三回就成了腔调。最容易撞、也最好换的两个：
  - 不是 A，而是 B → 从 A，变成 B；或把 B 提前，A 后置
  - 不在 A，而在 B → 与其说 A，不如说 B
  这一类对照句是本书的主要论证方式，**一章里超过五六处就要开始换**。
- **连接词扎堆**：同一个词连着出现两三次就扎眼。“可”轮着用成可／只是／然而；句首的“而”能删就删。

### 标点与加粗的定量门槛（2026-09-17 补）

修订前的密度：单章破折号最多 40 处（第七章），加粗最多 9 组（第七、十四章）。这是 AI 稿最明显的指纹。

- **破折号：每章不超过 8 处。** 能用冒号、句号、逗号、括号的地方，一律不用破折号。
- **加粗：每章不超过 2 组。** 只留给最核心的判准或结论一句。
- **例外是结构化标识**：并列的机制名（出错／筛选／拼接）、层级名（L1-L4）这类用来帮读者定位的加粗可以留，但也**只限这一类**。凡是“在段落中把某句判断拎出来强调”的加粗，都算超。

同一条规律适用于所有标点：**同一章里出现三次以上，就要问它是不是在替内容偷懒。**

## 四、结构

**每章**：开头一个问题（读者自己会问的具体问题）→ 中段从场景里长出概念，不要先定义后举例 → 章末回答那个问题，然后收束。

**每章每节都要有“但是”**（And–But–Therefore）：背景 → 冲突／代价 → 所以。把一节压缩成三句，中间那句不是“但是”，就说明这节只在罗列。

**章末要给结论，不要只给钩子**（Opening–Challenge–Action–Resolution 里的最后一步）：读者合上书，手里应该是一句能带走的判断，外加一个想去下一章的念头。只剩问题没有判断，读起来像一直扣着答案不给。

**例子按“有没有带来新判断”删，不按“多不多”删**。带来转折的留着；换个场景把刚说过的话再说一遍的，删掉。判断标准：删掉它，读者对世界的理解变不变。

**例子的真实性服从功能**。例子的任务是让读者对着一个具体现象想问题，不是提交史料：不编造可核对的事实，但**不必为史学细节、日期、机构沿革纠缠**。合成场景交代一句就够，同一句式全书只用一次。

**由此推出两条改稿纪律**（2026-09-11 补，血泪）：

- **不为一处考据去重写一段。**判断标准是"改掉它，读者对世界的理解变不变"。变（比如把砍手记成偷东西那种会让读者记住错东西的），改；不变（六比三还是"灌了六个"、词牌是不是格律的泄压阀），留一眼扫过去就够，不投入精力。
- **评审者的考据分不是改稿指标。**新读者每轮都会挑出一批"这个日期不对""这个说法有争议"，其中大部分落在规范明确放行的地方。先按规范筛一遍，只处理真正的硬错和可能误导读者的地方。

## 五、反重复与跨章引用

1. **同一个结论，全书只完整出现一次。** 别处一律短回指。
2. **术语复现可以，段落重讲不行。** 一个概念推完之后，不能在另一章换个说法再推一遍。
3. **一个案例只承担一件事。** 没承担新论证任务的例子，删。

### 跨章依赖的尺度（2026-09-17 定）

**一个案例不要在多处使用。** 某章需要类似的例子时，优先换一个本章内的，或者直接删掉——不要从别的章搬。

**不要写“第 X 章讲过的 Y”。** 这种写法读起来像作者在打补丁，而不是在讲事情。（旧版规范曾要求“写清这是第X章讲过的Y”，2026-09-17 废除。）也不要“我们说过”“前面讲过”这种空指。

**唯一的例外：依赖的确实是读者已经被反复教育过的核心概念。** 熵、控制搬运熵、松紧表、能比较不能打分、编码进化循环、三拍（碰撞／组合／筛选）、排热口／燃料口、缓冲层——这些东西在书里出现过多次，自然带出即可，不必交代出处。

判据一句话：**读者被这个词教训过三回以上，就可以直接用；只在一章里见过一回的案例或说法，不能拿来做另一章的论据。**

例：“癌细胞、归零的库存、被营收压扁的工作室、被论文指标碾碎的实验室”可以（四个都是前面详讲过的）；“第 3 章那两家面馆”“第 4 章那家后厨”“前面那几家守飞地的公司”不行（面馆、后厨、飞地各只在一章里出现过，拿去当另一章的论据就是跨章搬案例）。

## 六、作者定调（不得擅自改动）

- **系统**不言自明，用具体物带出来。
- **熵**是第一个核心概念，用的是**数学的熵**：可能性有多少。物理熵和信息论熵都只是它在具体领域里的展现——所以正文不必在“物理量”和“比喻”之间划界，也不必为借用热力学的语气而设防。（“从非线性到随机性”的推演路径不必进正文。）
- **控制**最自然的定义：**我们对系统做的任何事都叫控制**。第一章它是动作（在几个可能里挑一个），第二章给出它唯一的表现形式：**让某个维度上的可能性变小**（数学上叫压缩映射，正文不立这个词）。定义从未变过，变的只是抽象层级。不要把“控制”当成换过意思的词来写。
- **反脆弱性**是全书中心。控制和“崩不崩”没有直接关系，所以才需要它；它**不是绝对量**：高不等于不会崩（世界底色是随机），但与“不崩的概率”正相关。写的时候先给刚／柔两个中性描述（刚性＝控制更多，柔性＝控制更少，都不带褒贬），再破两个误区（控制越多越稳＝玻璃碗；撤掉控制就有弹性＝一滩水），然后说清**它和刚柔那条轴不是一回事**（刚／柔是同一根轴的两端：控制多／控制少；反脆弱是独立的那一个性质），结论是**它是分布不是加减法**——所以要问“控制落在了哪些维度上”。口径按白皮书 §2.4 定死：**判定只能按“哪一类冲击、哪一个维度、核心功能保住了／退化了／变好了”来问（可以比较，不能打分，并且可以被推翻）；它靠交换获得，系统能设计的只有交换面的大小。**跟塔勒布不写“他错了”，也不写“我用的不是他的意思”：他给的是一套方案，本书从系统整体往下推，问反脆弱性必须具备哪些性质。
- **不要承诺“这里没事”的判定。** 刚性和柔性都不是反脆弱性，两个极端反而更低；而“反脆弱性高”没有上限也没有标准。所以从第五章起大量章节处理的是“反脆弱性什么时候不高”，这本书能给的是比较、不是阈值——读者问“什么时候算够好”，答案是：把更差的那种指出来，删掉它。
- **演化／进化**的区分保留一句不含歧义的说明即可，不做成术语。
