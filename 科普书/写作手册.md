# 科普书写作手册（全书统一，撰稿前必读）

本手册约束全书的语调、概念用词与写作红线。无论人工还是协作撰稿，落笔前先读此文件；成稿后用它逐项自检。

## 0. 全书一句话主张
天下没有免费的午餐：控制不是消灭熵，是搬运熵。要想长存，唯有进化：看编码进化循环还在不在转。诊断用熵，治疗用编码。

## 1. 写作红线（每条来自项目 AGENTS.md，违反即废稿）
- 中文双引号用 ""，绝不用「」。
- 去 AI 味：删 "值得注意的是 / 此外 / 然而 / 毋庸置疑 / 显而易见" 等填充短语；不用否定式排比（"不仅……而且……"）；破折号与粗体克制，每章不超过 2–3 处。
- 让矛盾自己说话：摆出事实的冲突面，删掉所有替读者做情绪判断的形容词。参照第一章——全篇没有一处说"裁员很残酷""造假很可耻"。
- 概念为叙事服务：测试标准——把文章中所有系统理论术语删掉，文章还能站住，概念才放对了位置。不要写"这就引出了压缩映射的概念"这种元评论。
- 口语化但不轻浮：像兰小欢《置身事内》，不像咨询报告。用具体的人、瞬间、选择承载论证。

## 2. 语调样本（新章节开场必须模仿这种"具体场景切入"）
第一章开场："1926年，一对美国夫妇来到日本京都度蜜月……一次蜜月旅行，一个战争部长的记忆，一堆多年前的照片，最终决定了两座城市的命运。"——用一个人、一个瞬间、一次选择开场，而不是"本文将讨论……""在上一章我们提到……"。

## 3. 每章结构铁律
1. 开场：一个具体场景 / 人物 / 瞬间。禁止导言式开场。
2. 中段：让矛盾自己说话，从场景里长出概念，不要先定义后举例。
3. 结尾：留一个钩子（指向下一章的问题）或一句话收束。禁止"总结一下""综上所述"式套话。

## 4. 核心概念词典（全书用词必须一致）
- **熵**：随机性。一个系统可能处于的状态越多，熵越大。
- **控制**：降低特定维度上的随机性。
- **压缩映射**：控制的实现机制。f: X→Y，当 |Y|<|X| 时，多种状态被映射到同一状态。关键后果：总熵不会减少，只会转移到其他维度。
- **搬运熵**：控制不是在消灭熵，是在把熵从一个维度搬到另一个维度（捏气球：一头瘪一头胀）。
- **系统**：能够持续运转控制的东西。身份在于控制的组织方式，不在于组成部分。
- **刚性**：控制更多（控制量连续谱的一端），中性词。
- **柔性**：控制更少（连续谱另一端），中性词。
- **反脆弱性**：系统级定性指标，定义在系统整体上；是一幅维度分布图（哪里该刚、哪里该柔），不是刚性/柔性的加减法，不等于控制总量。
- **散热带宽**：系统释放熵的能力上限。两层天花板：①不是所有维度都能当"外机"；②能当外机的也有散热上限。熵产生速度 > 释放速度 → 崩溃。
- **子系统 / 母系统**：子系统存在于母系统内；某些维度由母系统代劳控制而处于低熵，这也是其脆弱根源。
- **编码**：系统控制规则的表达（规章制度、语法、基因序列）。用编码描述规则，系统演化 = 编码演化。
- **编码进化循环**：熵减（形成新编码）→ 熵增（新旧编码组合）→ 熵减（更新的编码）→ ……永无止境的正反馈。
- **生命以熵为食 / 寻熵者**：生命不是抵抗混乱的可怜虫，是主动寻找特定维度随机性并代谢排出的系统。多巴胺驱动寻熵行为。
- **共情**：编码对齐（熵减）+ 组合熵增。在共享编码下持续摄入新的随机性（以熵为食的镜像）。
- **内核维度 / 功能维度**：组织两层——内核 = 信息交换 / 共情（存活原因）；功能 = 信息以外的控制（赚钱、战斗力等伴随现象）。
- **均衡态**：在压缩映射约束下最可能的状态，有结构但僵化，失演化能力（如纳什均衡）。看起来熵低，其实是等死。

## 5. 两条定律
1. 天下没有免费的午餐：控制不是消灭熵，是搬运熵。
2. 要想长存，唯有进化：看编码进化循环还在不在转。

## 6. 诊断方法（第十二章展开）
动手前一句自检：熵会去哪个邻居家？那个邻居扛得住吗？发病后做断拍定位：看编码进化循环停在哪一拍——碰撞（第一拍）、组合（第二拍）、筛选（第三拍），停在哪拍修哪拍。原三问已融入定位前的两步侦察：控制盘点 + 熵流追踪。终极判准不变：这套控制体系是在给进化留空间，还是在把进化的门一扇扇关上？

## 7. 自指闭环及其两个前兆（第十三章展开）
- 自指闭环：一切内部批判都收敛到现有编码框架内解决——制造问题的编码，同时垄断着解决方案。
- 前兆一 编码反转：手段变成目的，编码变成现实。
- 前兆二 维度压缩偏误：编码天然偏好可度量维度，"不可度量就没有合法性"。
