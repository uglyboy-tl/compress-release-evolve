# 评审记录

## 规则

- **逐章往上推**：精修第 N 章 → 全新读者只读前 N 章 → 六维打分 → **≥48 才算成品**，才能动第 N+1 章。
- **每轮换新读者**，评审者只读正文，禁止读工作文档。
- 六维：完成度／可读性／可信度／记忆度／实用性／独特性，各 10 分。
- **版本管理**：每次修改记录版本号（v{章}.{序号}）、修改内容、分数变化。
- **质量监控**：若连续两轮分数下降，回溯到历史最高分版本重新修改。
