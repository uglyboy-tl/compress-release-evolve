# 大纲

14 章，约 40 万字符（约 14 万汉字）。**这份大纲是活的**：每精修完一章，就回来把那一行改准——精修后的内容才能沉淀进大纲，然后才谈得上影响后面的章。

配套：`写作规范.md`（怎么写）、`评审记录.md`（到哪儿了）、`工作流程.md`（怎么协作）。

## 二、章节表

### 1　系统与存在　6,031 字符　📋 40分　待大改

- **唯一的活**：打地基——随机性是万物底座，控制是应对随机的手段，系统是持续运转控制的东西。
- **怎么表达**：京都开场 → 随机性 → 因果性 → 努力 → 控制 → 系统
- **读者带走**：两个判断题（① 它有没有别的走法？② 被舍弃的是哪几条？）
- **待改**：加明确的开头问题；重组结构让"系统"定义更早出现；削减概念数量或加深论证

### 2　搬运工：控制到底做了什么　3,137 字符　📋 49分　达标

- **唯一的活**：控制不是消灭熵，是搬运熵。
- **怎么表达**：收拾房间 → 空调外机 → 压缩映射 → 你没办法控制一切
- **读者带走**：熵会去哪个邻居家

### 3　系统如何不死：散热与身份　12,452 字符　📋 44分　待拆分/重组

- **唯一的活**：排热口、两层天花板、睡眠、母系统与子系统。
- **待改**：信息密度过高（六个大话题挤在一章），需要拆分或重组

### 4　玻璃碗与海绵　10,538 字符　📋 46分　待小改

- **唯一的活**：反脆弱性——全书的中心。
- **怎么表达**：碗/海绵对比 → 刚性/柔性误区 → 两条腿 → 维度分布图 → 松紧表 → 后厨 → 癌细胞
- **读者带走**：紧在目的，松在方法

### 5　为什么好心会办坏事　13,810 字符　📋 49分　达标

- **唯一的活**：五个崩溃案例——控制落在本该释放熵的维度上。
- **注意**：空调外机画面与其他四个不等重，可考虑调整

### 6　消失的缓冲层　12,113 字符　📋 51分　达标

- **唯一的活**：缓冲层——平时看着多余，出事时是抗震垫。
- **读者带走**：量得出增值，量不出存活

### 7　进化的正反馈　11,082 字符　📋 48分　达标

- **唯一的活**：编码进化循环——新约束→新组合→新问题→更新的约束。

### 8　生命以熵为食　12,340 字符　📋 51分　达标

- **唯一的活**：生命不是抵抗混乱，是主动出门找混乱来吃。
- **读者带走**：一片叶子的价值不在它多有序，在于它带来了这个身体还没处理过的东西

### 9　进化本身也是系统　10,921 字符　📋 42分　待中等修改

## 三、跨章约定

- 篇幅不作硬指标，该长就长，该短就短
- 每章一个开头的问题，章末回答它
- 全书只让读者记六个词，其余一律大白话
- 每一章都要能被单独抽出来读
