# Compress, Release, and Evolve: A Unified Systems Theory

> **First published**: 2026-05-25 | [中文版](README_zh.md)

## What This Repository Does

Starting from a single axiom — **entropy = randomness** — this project builds a systems-analysis framework that uniformly explains phenomena across physics, biology, society, economics, and technology, then applies it to the real world.

The repository now contains:

- A plain-language introduction for general readers, plus a complete theoretical document
- An academic white paper in English (including dialogue with the traditions of Ashby, Holling, Ostrom, and others)
- Six theoretical extensions: causal hierarchy, nested systems, empathy mechanics, organizational derivation, nine philosophical questions, and a critique of eight disciplines
- Eighteen case studies: from personal sleep to corporate layoffs, from academic fraud to the US-Soviet rivalry, up to global governance

The same set of concepts runs through every scale — no separate vocabulary is invented for each domain.

## Core Claim

**Entropy = randomness. Control = compression mapping (entropy transport). Antifragility = balance between rigidity and flexibility. Evolution = entropy decrease (new codes form) → entropy increase (new combinations) → new entropy decrease, a positive feedback loop without end.**

The whole theory compresses into two laws:

1. **There is no free lunch**: control does not eliminate entropy; it transports it.
2. **To endure, evolve**: check whether the coding-evolution cycle is still turning.

Key difference from traditional approaches:

- **Traditional science** asks: "Given initial conditions, what happens?" (state derivation)
- **This theory** asks: "Given the current control distribution, which dimensions are being hollowed out by invisible entropy leakage under random shocks?" (risk assessment)

The two are not opposed: in domains with deep control and little leakage (particle physics, orbital mechanics), state derivation works; in domains with shallow control and high leakage (social systems, economic policy), state derivation fails systematically.

## Core Concepts

| Concept | Definition |
|---------|------------|
| Entropy | Randomness. The more states a system can occupy, the higher its entropy |
| Control | Reducing randomness in specific dimensions, i.e., compression mapping |
| Compression Mapping | $f: X \to Y$ where $\|Y\| < \|X\|$: many states map to one. **Key consequence: total entropy never decreases — it only transfers to other dimensions** |
| Rigidity / Flexibility | More control means rigidity and a narrower strategy space; less control means flexibility and a wider strategy space |
| Antifragility | Not an arithmetic of total control but a dimension distribution map: which dimensions should be rigid, which should be flexible |
| Coding | The expression of a system's control rules (regulations, grammar, gene sequences). Describing rules as coding turns system evolution into coding evolution |
| Coding-Evolution Cycle | Collision produces new codes (entropy decrease) → new-old combinations explode (entropy increase) → environmental selection → newer codes |
| Heat Dissipation Bandwidth | The upper limit of a system's capacity to release entropy. When entropy production exceeds release speed, collapse is only a matter of time |
| Entropy Seeker | Life is not a resistor but an active entropy seeker. Life feeds on entropy |

## Three Fallacy Patterns

The theory identifies three structural errors shared across disciplines. They are not individual cognitive biases but structural consequences of coded governance:

1. **Coding Reversal**: An operational code is mistaken for the system's fundamental purpose. Means become ends, codes become reality.
2. **Dimension Compression Bias**: Codes inherently favor measurable dimensions. "If a dimension cannot be measured, it has no legitimacy in the discipline."
3. **Self-Referential Closure**: All internal critiques are resolved within the existing code framework. The tool that patches the problem is itself the tool that produced it.

## Methodology: Diagnose with Entropy, Treat with Coding

**Diagnosis** keeps asking three questions:

1. What was compressed? Where was a single dimension over-emphasized?
2. Where did the displaced complexity go? Which unmeasured dimensions absorbed the entropy?
3. Where is evolution stuck? Collision, combination, selection — which beat broke?

**Treatment** answers: what new coding does the system need to restart its evolution cycle? Key constraint: the lever cannot be another layer of compression mapping — replacing metric Y with metric X just changes the dial. The real lever is adjusting incentive structures, so short-termism is no longer free and long-term accumulation becomes visible.

This repository documents the first public release of:

- **Entropy = randomness** as a unified analytical axiom
- **Compression mapping** as the mechanism of control, with the core corollary that total entropy only transfers
- The redefinition of **antifragility** as an independent property and a dimension distribution map (distinct from Taleb's usage)
- **Coding evolution** as a unified explanation of system evolution
- The **entropy-seeker hypothesis of life** (an active revision of Schrödinger's "negative entropy")
- **Three cross-disciplinary fallacy patterns** as meta-level diagnostic tools
