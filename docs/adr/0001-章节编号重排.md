# 第八、九章对调：理论篇收口在“进化本身也是系统”

2026-09-17 定：把原第八章（生命以熵为食）与原第九章（进化本身也是系统）互换。现在的 08 是“进化本身也是系统”，09 是“生命以熵为食”。

当时的考虑是理论篇要连着走完——“先说系统需要进化，紧接着就进入进化本身也是系统，保持进化其实也是保持进化本身的进化”，走到这里，《科普书》的理论知识部分才算讲完，从 09 开始（生命以熵为食、共情、组织）进入应用。

**被否决的方案**：保持原序（生命以熵为食在前）。否决理由：那样理论篇被一个偏应用的章切开，“进化”这条线还没收口就换了话题。

**后果**（已经发生的）：

- 章号散落在 `评审记录.md`、`待定清单.md`、`归档/`、以及历轮读者反馈的原话里，旧 08／09 的引用与现行号混在一起。`待定清单.md` 抬头写了“凡提到第 8／9 章请按新号读”，正文却一直没改——2026-09-18 才发现 B 节讲的“第九章”其实是现行 08。
- `07.md` 章末的钩子（“这架引擎的燃料是什么”）指向的是新 09，不是紧跟的 08。
- 归档文档里的章号一律保持原样，不复改。

**什么时候要翻这条**：如果哪天决定把应用篇（09 之后）再往前挪，或者 08 与 09 又有一次互换，那么所有工作文档必须一次性重编号，并且在这条 ADR 后面接一条新的，不要就地改这条。
